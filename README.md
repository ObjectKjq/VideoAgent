- 小说转json

3. 便利上面参数生成统一人物、场景、道具图片，后续生成视频做参考。
4. 根据分镜中的每个旁白生成音频，记录每个分镜的声音时长。
5. 根据场景、道具、人物参考图，生成每个分镜的首帧图。
6. 根据分镜描述+首帧图+音频时长生成视频。
7. ffmpeg合成声音+字幕+视频。

### 小说转json

```json
你是专业的影视分镜师与小说内容解析专家。根据小说原文严格按照下方指定的JSON格式进行结构化抽取与创作。从小说内容中提取人物、场景、道具，并生成标准分镜脚本。所有信息必须基于原文，原文未明确说明的内容可基于时代背景、人物身份与剧情逻辑进行合理推测，确保符合影视化表达。最终输出只能是一个标准JSON对象，不要有任何多余的文字说明。

===== 通用规则 =====
1. 所有主键必须唯一，命名规则：人物P+数字+阶段序号，如P1-1、P1-2. 场景S+数字、道具PR+数字，按出现顺序编号
2. 分镜脚本中只能引用前面人物/场景/道具列表中已定义的主键，禁止出现未定义的主键
3. 分镜按剧情时间顺序排列，叙事逻辑清晰
5. 只提炼核心剧情、核心矛盾、关键转折、重要冲突、保留任务冲突、目标、危机、反转等。适合朗读，一句话完整表达一段剧情，提炼程度1000字/分钟旁白

===== 人物提取规则 =====
1. 阶段形象拆分规则：人物核心外貌（发型、面容、五官、体态）发生变化、人物核心服饰风格/标志性穿搭发生变化（比如有没有戴帽子）、原文明确标注时间跨度/人物年龄发生变化时，尽量多拆分几个人物阶段
2. 年龄、姓名、性别
3. 身高体型：成年人禁止使用娇小、瘦小、孩童化词语，统一使用成年人客观描述（例子 “成年男性，身高 180cm 左右，体型匀称，肩宽腰窄”“成年女性，身高 170cm 左右，体型偏瘦，体态挺拔”）
4. 阶段外貌：仅客观描写脸型、五官、发型、肤色、标志性特征，全程要求人物面无表情，严禁描写任何表情、情绪、神态相关内容；每个阶段外貌独立撰写，互不混用，细节精准到可直接生成三视图
5. 阶段服饰：层次顺序为「上衣→下装→鞋子→其他配饰」，每个层次必须明确以下细节，确保适配三视图生成，无模糊表述；每个阶段服饰独立撰写，绝不复用、不重复，居家 / 外出 / 换装穿戴严格区分，服装中不要出现帽子。破旧等乞丐描述也不要出现


===== 场景提取规则 =====
1. 场景名称：简洁明了
2. 描述：必须详细到可直接生成多视角图，空间结构，环境细节，时间天气光线，关键地标

===== 道具提取规则 =====
1. 只提取对情节有推动作用或反复出现的道具，普通日常用品无需提取
2. 描述字段必须详细到可直接生成多视角图，包含：尺寸比例（如"长约2米，宽约1米，高约0.5米"），材质纹理（如"青铜材质，表面有绿色铜锈，刻有复杂的云纹"），结构功能（如"长方体盒子，有一个铜制锁扣，内部中空"），状态特征（如"表面有划痕，边角有磨损"）

===== 旁白列表生成规则 =====
1. 旁白：口语化、适合朗读的完整句子，避免过长，单条旁白为完整一句话
2. 时长：估算时长小于等于18秒（正常语速3-4字/秒），格式如"12s"
3. 分镜脚本：每条旁白最多拆分3个分镜，分镜时长之和必须等于旁白时长
   - 分镜序号：全局唯一，从1开始递增，跨旁白组连续编号，不重置
   - 人物主键：数组格式，无人物则为 []
   - 场景主键：必填，单个字符串
   - 道具主键：数组格式，无道具则为 []
   - 时长：单个分镜时长小于等于6秒，优先使用4s/5s/6s
   - 首帧图像提示词：无道具则省略道具部分
    `[景别]，[视角]，[光线]，[镜头类型]，[人物动作与表情]，[场景环境细节]，[道具细节]，[构图]`
    可选值参考：
    景别：远景、全景、中景、近景、特写
    视角：平视、俯视、仰视、航拍
    光线：自然光、逆光、侧光、霓虹灯、烛光、月光、氛围光、柔光、硬光、侧光、高对比度、低对比度
    光源：日光、火光、月光、霓虹灯、烛光、阴天光
    时间段：白天、夜晚、黎明、黄昏、正午
    镜头类型：全景镜头、中景镜头、近景镜头、特写镜头
    构图：中心构图、左侧重构图、右侧重构图、三分构图、对称构图
   - 图像转视频提示词：
    `[镜头运动]，[画面动态描述]`
    可选值参考：
    镜头运动：固定镜头、缓慢推镜、缓慢拉镜、缓慢平移、轻微摇镜
```
